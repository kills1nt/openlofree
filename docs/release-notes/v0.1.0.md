First public build of openlofree, a configurator for Lofree Flow 2 keyboards. Windows, Linux and macOS.

**Read this first:** reading the keymap is tested on a real Flow 2 Mac 84 over USB on Windows. Writing (keys, backlight, profiles) is covered by tests and the demo mode but has not been run on hardware yet. A factory backup is saved before the first write. Linux and macOS builds are untested on real machines.

## What is in it

- Desktop app: Keys, Lighting, Profiles, Device, light and dark themes, tray menu with one-click profiles, Demo mode that never writes to a keyboard.
- `flow2ctl`: the same features on the command line.
- Model: Flow 2 Mac 84 (USB `388d:0028`). The 68 and 100 key models are not registered yet.

## Install

| System | File | Notes |
| --- | --- | --- |
| Windows | `openlofree-0.1.0-windows-x64-setup.exe`, `.msi`, or `-portable.exe` | Not signed. SmartScreen: More info, then Run anyway. |
| macOS | `openlofree-0.1.0-macos-arm64.dmg` (Apple Silicon), `macos-x64.dmg` (Intel) | Not notarized. Right-click the app, Open. If macOS says it is damaged: `xattr -dr com.apple.quarantine /Applications/openlofree.app` |
| Linux | `.deb`, `.rpm` or `.AppImage` | The `.deb` and `.rpm` install the udev rule. With the AppImage, copy `70-openlofree.rules` to `/etc/udev/rules.d/`, run `sudo udevadm control --reload-rules`, and replug the keyboard. |

Checksums are in `SHA256SUMS.txt`.

## Use

Connect the keyboard by USB (wired switch position) and press a key to wake it. Close VIA and Lofree's configurator first, only one program can talk to the keyboard at a time.

## Known limits

- USB only. Bluetooth gives battery on macOS and nothing else.
- Battery is macOS only.
- Two Lofree devices at once (keyboard plus dongle): the first VIA interface found is used.
- The app icon is a placeholder.
