First public build of openlofree, a configurator for Lofree Flow 2 keyboards.

**This release is Windows only.** Linux and macOS installers are set up in CI but have not been built yet, so they will come in the next release. On those systems you can build from source, see the README.

**Read this first:** reading the keymap is tested on a real Flow 2 Mac 84 over USB on Windows. Writing (keys, backlight, profiles) is covered by tests and the demo mode but has not been run on hardware yet. A factory backup is saved before the first write.

## What is in it

- Desktop app: Keys, Lighting, Profiles, Device, light and dark themes, tray menu with one-click profiles, Demo mode that never writes to a keyboard.
- `flow2ctl`: the same features on the command line.
- Model: Flow 2 Mac 84 (USB `388d:0028`). The 68 and 100 key models are not registered yet.

The builds are not signed. SmartScreen: More info, then Run anyway.

## Use

Connect the keyboard by USB (wired switch position) and press a key to wake it. Close VIA and Lofree's configurator first, only one program can talk to the keyboard at a time. `Try demo` in the app runs without a keyboard.

## Known limits

- USB only. Bluetooth gives battery on macOS and nothing else.
- Battery is macOS only, so the Device screen shows no battery on Windows.
- Two Lofree devices at once (keyboard plus dongle): the first VIA interface found is used.
- The app icon is a placeholder.
